Interactive **Power BI dashboard** built using the Blinkit sales dataset to analyze sales performance, product insights, and regional trends. Features dynamic KPI cards, DAX measures, Power Query transformations, interactive slicers, and business-focused visualizations.

🔗 **GitHub:** https://github.com/Prince-Saxena/Blinkit-Sales-Dashboard  
📄 **Dashboard PDF:** https://github.com/Prince-Saxena/Blinkit-Sales-Dashboard/blob/main/Blinkit%20Dashboard.pdf
